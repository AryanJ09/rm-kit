# Working agreements

- **Ask in one batch, then wait.** List every question together with a recommendation for each. Do not build until the
  owner says go.
- **Say what you understood.** Restate the owner's answers so a misread shows up before code does.
- **Do not decide for the owner when it changes how things look.** Pressed colours, tones and header looks are theirs.
- **Verify what the owner will see.** Check the Storybook sidebar, the phone at full size and every state, not only that the
  checker passes.
- **Report gaps honestly.** Roles that are only the nearest fit, differences from Figma, and anything not checked go in
  the summary.
- **Commit only when asked.** The owner approved one commit of all `apps/v4` work on 2026-10-30.
